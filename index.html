Arranque

Autenticación por cabecera x-api-key. Servidor https://placapi.com/api. Sin SDK obligatorio: es HTTP y JSON.

Con curl
curl -X POST 'https://placapi.com/api/consulta' \
  -H 'x-api-key: pk_live_TU_CLAVE' \
  -H 'content-type: application/json' \
  -d '{"placa":"ABC123","docType":"CC","docNumber":"1020304050"}'
Con fetch, sin instalar nada
const r = await fetch('https://placapi.com/api/consulta', {
  method: 'POST',
  headers: {
    'x-api-key': process.env.PLACAPI_KEY,
    'content-type': 'application/json'
  },
  body: JSON.stringify({
    placa: 'ABC123', docType: 'CC', docNumber: '1020304050'
  })
})

const { data } = await r.json()
console.log(data.informacionGeneral.marca) // MAZDA
Prepago por consulta, sin cuota mensual. consulta-full cuesta 2 créditos; el resto, 1. Repetir la misma consulta dentro de la ventana de caché no vuelve a cobrar. Una consulta sin resultado (404) trae 10 gratis al mes por cada código de sin-resultado; a partir de ahí cobra como una normal. El límite es de 1.000 consultas por minuto por clave. Tarifas vigentes en placapi.com/comprar.
