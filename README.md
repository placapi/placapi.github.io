# placapi.github.io

Sitio de la **referencia abierta de [PlacApi](https://placapi.com)**: la especificación
OpenAPI 3.1 de los 36 endpoints, renderizada, más la colección de Postman.

<https://placapi.github.io>

| Archivo | Qué es |
|---|---|
| `index.html` | Portada: qué se puede consultar y cómo arrancar |
| `reference.html` | Referencia interactiva, generada desde `openapi.json` |
| `openapi.json` | Especificación OpenAPI 3.1 |
| `postman.json` | Colección de Postman |

Los dos JSON son copias de [`placapi/placapi-openapi`](https://github.com/placapi/placapi-openapi),
que a su vez se generan desde el catálogo vivo de la API. La versión siempre vigente está en
`https://placapi.com/openapi.json`.

PlacApi no es una entidad oficial del Gobierno colombiano.
